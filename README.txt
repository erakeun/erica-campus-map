V2 변경사항
- 기존 이미지 하단 범례 삭제
- 하단 건물 목록을 실제 HTML 텍스트로 재구성
- 사용자가 수정한 건물명과 블로그 링크 유지
- 검색 시 지도 번호 + 건물 목록 동시 강조
- 지도 확대/축소 100%~300%
- Ctrl/Cmd + 휠 확대 지원
- 지도 이미지를 항공사진 부분만 잘라 4096×1860으로 리샘플링

링크 수정
- index.html의 BUILDINGS 배열에서 url만 수정
- url:""이면 클릭 불가 / 목록에는 준비중 표시

좌표 확인
- 사이트 주소 뒤에 ?debug=1
